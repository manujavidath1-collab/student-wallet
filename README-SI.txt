MY STUDENT WALLET – PREMIUM BLUE EDITION

මෙය ඔබගේ පෙර Student Wallet PWA එකේ updated version එකයි.

අලුත් Features:
- Blue Premium interface
- Dark / Light mode
- Monthly category chart සහ පසුගිය දින 7 වියදම් chart
- Daily spending limit alert
- Category-wise monthly budget limits
- Savings goals සහ progress
- පැරණි expense tracking, CSV export සහ JSON backup

DATA ආරක්ෂාව:
- පැරණි expense key: studentWalletExpensesV1
- පැරණි allowance key: studentWalletAllowanceV1
- ඒ keys දෙක වෙනස් කර නැහැ. එම නිසා පැරණි browser එකේ තිබෙන වියදම් සහ allowance අලුත් version එකෙන් කියවිය හැක.
- අලුත් budgets, daily limit, goals සහ theme වෙනම localStorage keys වල save වේ.
- Browser data clear කළොත් local data මැකෙන්න පුළුවන්. නිතර Backup JSON Download කරන්න.

භාවිතය:
1. ZIP එක Extract කරන්න.
2. My_Student_Wallet_PWA folder එක VS Code වලින් Open කරන්න.
3. index.html එක browser එකෙන් පරීක්ෂා කරන්න. PWA install / offline සඳහා HTTPS hosting අවශ්‍යයි.
4. GitHub Pages වැනි HTTPS hosting එකකට upload කළ පසු Android Chrome > ⋮ > Install app / Add to Home Screen තෝරන්න.

සටහන:
පැරණි app එක තිබුණු එම browser profile එකෙන්ම අලුත් hosted version එක විවෘත කරන්න. වෙනත් browser/device එකක localStorage data ස්වයංක්‍රීයව එන්නේ නැහැ.
